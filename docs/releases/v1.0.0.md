## VA v1.0.0 · macOS 桌面 3D 角色

### 安装

下载 `VA-1.0.0-mac-arm64.dmg`，把 `VA.app` 拖到「应用程序」后打开。此安装包面向 macOS 13 或更新版本的 Apple 芯片 Mac。豆包实时通话字幕需要 macOS 26 和本机中文语音识别。

安装包使用临时签名，尚未经过 Apple 公证。请在核对 SHA-256 后安装；如系统提示无法验证开发者，可按 Apple 的说明处理。[Apple 安全打开应用说明](https://support.apple.com/zh-cn/102445)

### 功能

- **桌面角色** · 透明悬浮窗口、自定义名称、记住摆放位置、可调比例、全身与半身、鼠标穿透和点击摸摸互动。附带默认 VRM 封面角色。
- **3D 模型库** · 搜索、预览和导入 VRM、GLB、glTF、PMX 等模型。使用前可检查文件、骨骼和动画能力。模之屋与 VRoid Hub 入口可跳转到模型来源。
- **动作与自拍** · 内置舞蹈、问候、情绪、说话和摆拍动作。可配置自定义动作与默认台词。智能体可以根据对话选择动作并写出台词，也能拍摄透明 PNG 自拍。
- **本地 Agent** · 接入 Codex、Claude Code、OMP、DeepSeek Harness 和自定义 Agent。OMP 和 DeepSeek Harness 支持从绑定记录打开原会话。可逐条移除或按 Agent 清空 VA 的记录。DeepSeek Harness 使用原客户端的会话标题，自动隐藏已归档会话，并可读取角色 Prompt、显示回复字幕和触发动作。已绑定的 Codex、Claude Code、OMP 会话也可同步新回复到桌面。
- **豆包与机器人** · 联动豆包 macOS 客户端和通话字幕。可通过 AstrBot 或 OpenClaw 将频道回复送到 VA，并通过支持附件的集成发送自拍。
- **语音与字幕** · 支持 macOS 本机音色、火山 TTS 和本地 ZipVoice 音色复刻。朗读时口型跟随音频，气泡支持彩色 emoji 和颜文字。配置 ZipVoice 时可切回其他音色或设置页。
- **屏幕与音乐** · 可以配置屏幕观察间隔并交给选中的本地 Agent 处理。支持在本机检测音乐后跳舞，每项功能都有独立开关。
- **命令行与自动化** · 通过 CLI、MCP 和 VA Desktop Skill 控制动作、自拍和配置。角色 Prompt 在桌面角色设置中统一编辑。

本地音色复刻需要额外安装 ZipVoice 模型和 Python 环境。Agent、机器人和录屏功能按需启用。[使用说明与权限](https://github.com/yincongcyincong/VA/blob/main/README.md)
