    说话风格

    风格影响说话动作、VA 朗读的语速和音量。实时通话播放原声，角色口型跟随声音。

    朗读音色

    开启后朗读动作自带的台词。对话语音和单独朗读由各自的设置控制。

    当前音色

    ZipVoice 在本机复刻音色。选一段约 3 秒的清晰人声，并填写录音里实际说的话。

    运行路径

    缺少运行环境或模型时，可在项目目录运行 make zipvoice-tts。

    模型资源

    使用火山时，朗读文本由火山引擎处理。

    接入方式

    保存 Agent 和工作目录后，使用 Codex 或 Claude Code 的会话 ID 绑定。点击记录中的「打开会话」可在终端续接。

    会话绑定记录

    选择一个 Agent 查看绑定记录。

      打开本机豆包的一个对话，再绑定。关闭设置窗口后，桌面仍会显示新回复。

      语音输入在豆包客户端的输入框按住空格。绑定后，新回复会显示在角色旁边。

      通话字幕

      在豆包客户端通话。VA 用 macOS 在本机转写豆包播放的声音。

      在目标频道运行 /va route 获取路由。VA 展示机器人已经发送的回复。

      共用 Prompt

      应用到本地 Agent、豆包客户端能力同步、OpenClaw 和 AstrBot。可用 {{name}} 引用当前角色名。
